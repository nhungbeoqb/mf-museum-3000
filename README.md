Entry for the [Museum of the Year 3000](https://make.fun/bounty/u-donrulezz-museum-of-the-year-3000-b727a0bb) bounty on make.fun: one line, the museum label a museum in the year 3000 puts beside an ordinary object from today.

`main.py` (Python 3 stdlib only) writes the label to `/output/entry.txt` and self-checks the gate (UTF-8, single line, 1–200 characters, not only whitespace):

> Sticky note, c. 2024. The lock itself. Humans wrote the secret on it, then stuck it to the door it opened.

The joke is the year-3000 misreading: the curator takes the password sticky note for the lock itself — a true, absurd fact about what the thing was for.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
